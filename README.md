## Featured Work

### 🔬 Breast Cancer Detection — YOLOv11

> Automated tumor detection in MRI scans. A diagnostic assistant that highlights suspicious regions, reducing false negatives in early-stage detection.

| Metric | Score | |
|---|---|---|
| **mAP@50** | `91.7%` | Detection accuracy |
| **Precision** | `98.1%` | When it predicts tumor, it's right |
| **Recall** | `81.2%` | Catches most tumors in test set |
| **Dataset** | `1,007 MRI slices` | Duke Breast Cancer Dataset |

**Stack:** `PyTorch` · `YOLOv11` · `OpenCV` · `Python`  
📄 **Status:** Research complete · Paper in preparation  
🔗 [Repository](https://github.com/maashg3l4)

<br/>

### 🌐 VisDrone Detection Toolkit — Open Source Contributor

> Contributed to a YOLO-based aerial detection toolkit covering 33 models, training pipelines, benchmarking, and Hugging Face deployment.

**Impact:**
- ⭐ **84 stars** · 🍴 **33 forks** on GitHub
- 🤗 **Live Space** deployed on Hugging Face ZeroGPU
- 🛩️ **10 object categories** for aerial imagery

**Stack:** `Python 3.8+` · `PyTorch 2.0+` · `Torchvision` · `YOLOv8/v11/v26`  
🔗 [Repository](https://github.com/dronefreak/VisDrone-dataset-python-toolkit) · [Live Demo](https://huggingface.co/spaces/warfazeee/visdrone-aerial-detection)
