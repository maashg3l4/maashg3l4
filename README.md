## 👋 About

I'm a CS undergraduate at **IUBAT** building **computer vision models for medical imaging**, with a focus on object detection (YOLOv11).
I evaluate models properly (held-out test sets, per-class metrics, error analysis) and deploy them as working web services.
I also build the full stack around the models: APIs, dashboards, and front ends.
